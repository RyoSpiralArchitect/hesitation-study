# English companion

[Observation notes](../../research-notes/) · [Shared protocol](../open-ja/protocol.md) · [English amendment](protocol.md)

Each English item carries the ID of its Japanese source. The input translator did not receive a gold index. The gold text here is the translated choice at the original index. Twelve paired translations were spot-read before English answering; no translated item contained duplicate options. Five English questions later proved to contain the answer name. The paired 123-, 120- and 119-item sensitivity checks reflect successive [errata](errata.md).

The responding snapshots, cells, response schema, sampling parameters and graders match the Japanese experiment. Shared generation and offline analysis code reside in [open-ja](../open-ja/). This directory contains the English prompts and data. The cost ceiling of USD 8 covers translation, all responses and both sets of grading requests.
