# Open-response study · 2026-11-24

Freeze before any response is read. Sample 128 distinct questions from JAQKET dev2 with seed 20261124. Choose three distractors from each original pool and shuffle with the gold. Archive IDs, text and options. The open arm only sees the question. MC displays the four names and requests the same verbal answer. Every arm permits withholding an answer. One draw per cell, no tools, no numeric confidence elicitation. API default sampling (4.1 and 5.4 across conditions), 1024 completion tokens including reasoning; log truncations without redrawing. This is a Japanese short-answer pilot.

1. Primary measure: proportion of all 128 items with a concrete wrong identification, open mini B minus A. Also report all-item correct, vague, abstain, unresolved/invalid, and error conditional on substantive answers. Examine paired transitions out of the A errors. Estimate the B−A difference-in-differences for open vs MC using the same item draws. Repeated names can be genuinely the same wrong answer; judge canonical candidate agreement is a lower-fidelity proxy subject to alias review.
2. Open A/B/C on GPT-4.1 mini, GPT-4.1, and one GPT-5.4 snapshot with reasoning effort none and low. C selectivity = P(hedge | concrete wrong) − P(hedge | correct). Report it and its change versus A with counts and paired intervals; compare low and none. The two conditioning sets can change. No inference of a size threshold from these few configurations.
3. In mini, cross first answer vs rewrite of that item's exact A response with the identical B discretionary and F mandatory suffix. Report pause and hedge prevalence in the four cells, structure and wording contrasts and their interaction. Check response preservation in both rewrite cells. Include the original A wording, no question or gold in rewrites. Both of each item's edits share A as source.
4. Frozen, condition-blind GPT-4.1 judge scores unique (item,reply) pairs. Judge sees no arm or system prompt. Separate vague from abstention, tag extra factual content without claiming its accuracy. Exact primary unit is an incorrect answer to the question, not all false factual clauses. Independently inspect 64 random distinct graded replies blinded to judge and condition, plus sampled disagreement examples. If judging fails, preserve unresolved rows. Keep original scores after audit. Report selected examples as illustrations.
5. Bootstrap 10,000 times with seed 20261125, resampling all configurations of a question together. Percentile 95% intervals; conditional metrics omit undefined bootstrap replicates and report support. Other contrasts exploratory. Equal 128 denominators; if a technical output is absent it is invalid. No result-dependent expansion. API budget US$5 across generation and judging.
